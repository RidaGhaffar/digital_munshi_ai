# DigitalMunshi

DigitalMunshi is a legal assistant project with a Flask backend, frontend UI, OCR support, and MLflow-based experiment tracking.

## Project Structure
- backend/ - Flask API and ML services
- frontend/ - Streamlit frontend
- database/ - SQL schema and migrations

## Quick Start
1. Install backend dependencies
2. Run the backend server
3. Run the frontend

## Notes
- MLflow runs are logged in the backend project
- Docker support is available for the backend
